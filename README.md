# ballsdex-role-reward

Ever got a support server for your dex and has a channel that other dexes spawn in? Well, this is for you. This package gives a role, that has access to that channel (that you specify), to a user that reached the required progression in your dex. Cool, right?

## Installation

Add the following into your `config/extra.toml` file.

```toml
[[ballsdex.packages]]
location = "git+https://github.com/seiftheman/ballsdex-role-reward.git#main"
path = "role_reward"
enabled = true
```
